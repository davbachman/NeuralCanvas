# Course plans and validation

The [28-assignment sequence manifest](../sequence.json) is the canonical order.
See the [migration record](COURSE-28-MIGRATION.md) for old-to-new paths and packaging.
The [complete-course validation report](COURSE-28-VALIDATION.md) summarizes the
current implementation and local checks.
Start with [the current semester schedule](REMAINING-SEMESTER-SCHEDULE.md),
[assignment design](ASSIGNMENT-DESIGN.md), and each assignment's instructor guide.
[The dataset browser update](DATASET-BROWSER-ASSIGNMENTS.md) documents the current
dataset-selection workflow. [The top-k sampling lab](TOP-K-SAMPLING.md) documents
the current decoding construction assignment and new app operations.
[Post-training interpretability](POSTTRAINING-INTERPRETABILITY.md) records the
current SAE and steering checkpoints, recipes, and validation.
[The interpretability extension](INTERPRETABILITY-EXTENSION.md) preserves the
earlier app support and narrative-only checkpoint evidence.

The other reports preserve the evidence, limitations, app revisions, and earlier
numbering under which they were written. They are public summaries; their paths
to `pilots/`, trained `reference/models/`, browser exports, and solution-based
test scripts refer to the private NeuralCanvas-Coursework checkout. Current
public packaging and verification commands are in [the course guide](../README.md).
Historical results do not supersede current handouts or validate changed recipes.
