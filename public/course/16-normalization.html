Part A — Normalize features within each token

Add Layer norm before attention, before the shared MLP, and immediately before the vocabulary projection. Each normalization has independent learned scale and offset Params of shape (16); initialize scale to ones and offset to zeros. Keep epsilon at 0.00001.

Wire the graph to implement:

  • R = X + Attention(LN1(X))WO
  • H = R + MLP(LN2(R))
  • logits = LNfinal(H)Wvocab + bvocab

Start with a copy of Assignment 15. In the dataset browser, choose Football stories → Narrative generation, set Training targets to Final position only, and click Use this dataset. Keep the final-logits Slice for this part. The shortcut inputs remain X and R. Determine which wires must move; putting normalization on a shortcut changes the assigned model. Train from fresh parameters for 10 epochs in one run using the settings below, then save transformer.json. Keep this trained file before making the next change.

Part B — Learn from every position

Your transformer produces vocabulary logits at every position but has learned from only the last one. With causal masking, every row can instead predict its own next token in the same forward pass.

In a separate copy, open the dataset browser, choose Football stories → Narrative generation, set Training targets to Every input position, and click Use this dataset. It contains exactly the same documents, split and input windows as Part A; the targets now contain 32 shifted token IDs. For an input t0…t31, the targets are t1…t32.

Remove the final-logits Slice and connect all logits to the loss and output Softmax. Retain every causal mask: the target for an earlier row also appears later in the input, so allowing that row to attend forward would leak the answer. Keep the single transformer block and width 16. Randomize and train from fresh parameters for 10 epochs in one run, then save all_positions.json. Keep this file for Assignment 17.

Part C — Make a comparable evaluation copy

Save a separate copy of the trained Part B model, use the dataset browser to select Narrative generation with Training targets: Final position only, click Use this dataset, and restore the final-logits Slice. Do not randomize or train this copy. Save last_position.json. Only all_positions.json and last_position.json must have identical learned parameters; transformer.json is a separately trained baseline.

Use held-out inference on transformer.json and last_position.json to compare accuracy and loss on the same final-position task. The all-position metrics average different predictions and cannot be compared directly with those numbers. Both models train for 10 epochs with the same architecture, optimizer settings and input windows. Ask whether learning at every position improves held-out final-position prediction at the same number of passes and optimizer updates. Training times can differ, and fresh random initialization can affect the result. The grader checks all three models and their final-position losses; no written comparison is required.

Training positions can be processed together; autoregressive generation still chooses one token after another. Thirty-two targets per window does not promise a 32-fold speedup.
